# Page Patterns — proven structures to reuse

## Chapter / masterclass page (the "Hermes Agent" pattern)

1. **Masthead hero**: full-bleed color panel (electric blue), giant serif display title stacked in 2 lines, fine line-art rays behind, chapter chip top-left.
2. **Chapter title**: mono breadcrumb ("MASTERCLASS · CHAPTER 06") → big serif "Always *On*." with the accent word italic in gold or blue.
3. **Promise paragraph**: italic serif, 2-3 lines, what this chapter does for you.
4. **Topic pills row**: 5-7 small chips previewing the sections.
5. **Sticky section nav**: numbered chips (6.1, 6.2 ...) that fill as you scroll.
6. **Sections** on the standard rhythm, each with: kicker chip, headline + accent word, serif subtitle, metaphor card, content, action strip.
7. **One parchment schematic illustration** per major concept (the sepia Da Vinci style).
8. **Honesty/callout beats**: amber cards for "honesty beat, on camera" moments.

## Research / strategy report (the "counter-strategy" pattern)

1. Kicker + two-line headline where line 2 is the gradient payoff line.
2. Meta row: 3 key facts (target, subject, stakes).
3. Numbered sections with `01` gradient chips.
4. Stat row (4 tiles) before any prose.
5. Evidence blocks: quote cards with ▲likes, verdict tables with pill chips.
6. Callouts alternate teal (insight) / violet (signal) / amber (warning) / red (threat).
7. Footer: sources + method line, dim, centered.

## Verdict / audit screen (the "Bouncer" pattern)

1. Title row: emoji-free icon + "VERDICT: <name>" in mono.
2. Gate rows: bold gate name, PASS/FLAG/DENY chip, one-line evidence, indented findings in the gate color.
3. Tier banner at the bottom: full-width, tier color, unmissable.
4. Chapter 7 tier language: AUTO-ALLOW (green) / ALLOW + LOG / ASK FIRST (amber) / DENY & QUARANTINE (red).

## Dashboard (the "operator console" pattern)

1. KPI strip first: 3-4 big numbers with ROI framing ("$X extracted from $Y").
2. One scroll, panel sections, each panel self-explanatory without the others.
3. Live data gets a freshness stamp; stale data says so honestly.
4. 3D/graph views get a full-bleed dark stage with filter chips, never squeezed into a card.
